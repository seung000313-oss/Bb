# 버전 기록

현재 배포: **v5.6**

`롤백` = 현재 버전을 폐기하고 바로 이전 버전(`versions/v이전.html`)을 index.html로 복구. 사용자 데이터(localStorage)는 그대로 유지.

## 운영 메모 (2026-11-22)
- **보관**: versions/에는 최근 5개 버전만 둡니다. 그 이전 버전은 git 이력에서 복구할 수 있어요(`git log -- versions/v2.8.html`).
- **미리보기**: 배포 전 `versions/next.html`에 먼저 올려 확인한 뒤 index.html에 반영합니다.
- **자산 분리**: 모션 데이터 `assets/motion.js`(키프레임 축소), 특성 데이터 `assets/traits.js`. 특성 업데이트 시 traits.js의 TRAIT_DATA 구간을 교체합니다. versions/의 보관본은 자산을 안에 넣은 단일 파일입니다.
- **앱(PWA)**: 루트의 manifest.json·sw.js·icons/. 게임 화면은 네트워크 우선이라 배포하면 바로 반영되고, JS·아이콘은 저장본을 쓰며 뒤에서 갱신. 큰 변경 때 sw.js의 CACHE 이름을 올리면 저장본을 한꺼번에 비움.
- **PvP**: 공개 MQTT 브로커(broker.emqx.io → hivemq → mosquitto 순서로 시도)를 WebSocket으로 거쳐 통신(방 코드 4자리, 토픽 dny5/코드/h·g). 방장 기기가 경기를 계산하고 상태를 참가자에게 보냅니다.
- **밸런스 점검**: `tools/balance.html`에서 버튼 한 번으로 안타 구성·볼넷 비율을 리그 기준과 비교합니다.
